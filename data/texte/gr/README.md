# Texte grecești

Adaugă fișiere XML TEI sau JSON în subdirectoare numite după autor (de exemplu `Aristotel/`), apoi include căile lor relative în `data/texte/texte.json`, folosind prefixul `gr/`.

Pagina „Texte” afișează separat autorii greci și pe cei latini. Formatul JSON este descris în `data/texte/README.md`.
